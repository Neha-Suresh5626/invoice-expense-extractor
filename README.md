# Smart Invoice Processing and Expense Analytics Platform

## Features

- OCR-based invoice processing
- Layout-aware invoice understanding
- Vendor name detection
- PDF and image invoice support
- SQLite database integration
- Excel export
- Dashboard analytics
- Flask web application

## Technologies Used

- Python
- Flask
- Tesseract OCR
- SQLite
- Pandas
- HTML/CSS

## Run Project

```bash
pip install -r requirements.txt
python app.py
```
